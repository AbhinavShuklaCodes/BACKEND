What is an IP address?

IP = address of a computer/device on a network.
👉 ISP (Internet Service Provider) IP address assign karta hai.


What is a Port Number?
Port number = device ke andar specific application/(service) ka address.






What is a Server?
ek computer/program jo requests receive karta hai aur response deta hai.

Simple example:

👉 Tum browser me youtube.com open karte ho
👉 Tumhara computer request bhejta hai
👉 YouTube ka server request receive karta hai
👉 Server required data/video details bhejta hai
👉 Tumhare browser par YouTube open ho jata hai.
